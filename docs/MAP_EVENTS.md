# v0.13.0 地图节点与奇遇

## 节点与拓扑

16节点、8层、所有原连线保留。原营地6/12改名工坊并使用铁砧图，仍强化牌；原工坊3/8/14改名休整并使用营地图，删牌或备战。旧破寨节点5改普通战斗，精英仍为2/9两处，改关隘图与“关隘”名称，不增加精英密度。普通战斗仍交叉军旗；精英将5血，决战将固定9血。

## 休整与强化

- 轻装上阵：选择一张永久牌，确认删除；沿用原可删至空牌组规则，不涉及每回合免费移动牌。
- 养精蓄锐：下一战初始多抽2张，进入战斗时消耗。已有备战时禁用，不能叠加或因续局/悔棋重复获得。
- 工坊：选择一张可强化牌确认强化。`card_upgrades.gd` 注册表统一目标ID、资格与描述，当前仅短剑→短剑·淬锋、长枪→长枪·淬锋。未注册牌不自动猜测强化效果。

## 三奇遇

每个奇遇节点使用地图随机源独立抽取药庐/行商/兵书，各1/3，允许重复。事件身份、行商报价和口诀随机种子在地图生成时固定并存档，不按生命或牌组筛事件。

- 药庐：回复1命（上限5），或获得一张调息。满血时疗养禁用，仍可取牌或离开。
- 行商：固定三份互异类型报价，2角色专属+1公共。选择报价及交出的永久牌后确认，一换一，取消不损失；确认页展示换入牌费用及效果。空牌组不能交易。
- 专注抄写：立即复制选中的任意永久牌，并额外加入一张“疲惫”。无同名数量限制、强化ID完整保留，选择疲惫自身也可正常复制。
- 课后作业：登记选中牌的精确ID，下一场胜利无常规战后收益，但当场交付这张复制牌。确认时不提前入牌组；多个待交付作业都指下一场，不延长到后续场次。
- 只记口诀：在当时可强化的实体牌副本中等概率抽1张；采用节点固定种子，预览/取消/重载不能重抽，不允许手选目标。没有候选则禁用，仍可复制或离开。

## 事务、战后与存档

选择与确认分离，选择/取消无永久变化；确认时修改牌组/生命/备战/代价并一次性标记节点完成、保存。每个节点最多领取一次，结果返回地图展示。免费移动牌永不进入复制/交易/删除候选。

疲惫是2费普通负面牌，不是消耗牌：抽到立即扣1当前能量，最低0。0能量抽到不扣、不记录欠费，之后补能不补扣。同回合洗回再次抽到也正常触发。游戏手牌跨回合保留，因此每个后续玩家回合先重置能量（含吐纳），再按手中疲惫张数各扣1。花2费打出进弃牌堆，已扣不返还；手牌超限时也可依原规则弃置。疲惫不进初始牌/普通奖励，可被删除、交易和复制。

课后作业只在下一场胜利结算，不在入场扣除或提前给牌；普通、关隘、决战及调试跳过均使用同一入口。常规加牌/删牌等奖励抑制，而任务交付独立展示，胜利、行军和解锁正常。下一场结算后第二场恢复正常奖励。保存包含待交付/已交付列表和本场结算标记，重载/重复结算/悔棋不重复发牌。

存档包升级schema5，原储存键保留但旧schema不读取；不迁移旧Demo局，不删除音量与角色解锁。运行时每个当前版本节点均可续局，未确认选择续局回根选项，不产生副作用。
