# v0.10.0 验证记录

基于已发布 v0.9.2，保留地图曲线缓存、批量绘制、静止时不重画以及 Web 触摸滚动回归。

- 全套 `scripts/verify.sh`：脚本解析、启动、核心、角色开局、路线、地图交互与状态安全、卡牌、教学、空格、黑红地图、字体和地图性能测试。
- 新增敌方遭遇测试：1319 项，覆盖所有模板合法走法、血量、固定生成、五类规则、倒计时/定身、援军上限/跳波、加步叠加、伤害顺序、最新站位决策、撤销与续局、弹窗阻断输入以及连续移动动画。
- 教学：166 项，显式断言象为3血、三次短剑伤害、第三剑死亡、能量耗尽及踏马保留。
- 原生 OpenGL 实际渲染：1280×940、390×844、844×390、360×640，共35图、123项断言。覆盖精英/Boss、新棋子、军阵说明、当前范围但无未来落点。代表图在同版本 verification/native。
- 手机棋盘原1逻辑像素线在360px缩放下会消失，改为1.5逻辑像素抗锯齿线，逐图复核。
- 字体重新构建并校验原字形、宽度与覆盖；Web导出执行 PCK 预算审计。CI 保留真实 Chromium 四尺寸地图进入/返回/续局/空格/触摸拖动流程。

存档：schema3 独立命名空间，旧局不迁移也不删除，解锁和设置保留。需要重新开局。

边界：自动化视口和原生渲染不等于实体手机帧率、触觉或音效验收。长局战略平衡仍需实际试玩；新增血量与军阵改变战斗难度。
