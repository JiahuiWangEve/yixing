# v0.14.0：坚城与守阵

第一章决战结束仍结算战后奖励，然后开启全新的第二章地图。兵书课后作业先交付选定的复制牌，再跨章；血量、永久牌组、强化、角色和未消耗的养精蓄锐延续，不自动治疗。第二章决战结束整局。第一章通关解锁马的功能保留。

第二章沿用象棋移动规则，不叠加第一章轮防、反扑或额外移动词条。普通将4血、关隘将6血、决战将9血；重卒2血、重象4血，不屈士2血。普通卒1血、马2血、普通象3血；车炮按模板为1或2血。每个敌方阶段每子最多移动一次，攻击仍在移动之前、独立于移动倒计时。

## 不屈

不屈士或象被击倒后离场，原始出生格保留不占位标记，不挡路、不算炮架，也不能继续攻击该标记。两个完整玩家操作回合后，在敌方阶段结束时尝试满血复归。

- 第4玩家回合中击倒：完整开放第5、6回合，第6敌方阶段末复归。
- 第4回合开始、玩家输入前被流血击倒：开放第4、5回合，第5敌方阶段末复归。
- 原出生格有任何棋子、玩家或木桩时等待，允许主动占住该格。
- 复归当阶段不攻击、不移动，移动倒计时重置为3；下阶段正常攻击。
- 击杀敌将立即结束，取消复归与未到场援军，无须清空守军。

## 有限增援

每波提前一个玩家回合提示入口；指定敌方阶段末到场，当阶段不行动。最多同时存活2名增援，每阶段至多到场1名。入口占用或达到上限时最多顺延2个敌方阶段，再取消，不积攒爆发。若同阶段复归和增援竞争出生格，先处理复归。所有波次有限，不加额外战后奖励。

## 将的防守

将不再因为“离玩家更近”主动离开护卫。原地进入候选，实际公开攻击危险优先，其次有效护卫、接近路径的控制及逃生空间，接近评分时留守。侧退方向相对玩家位置，不硬编码棋盘顶部为安全区。不读取玩家手牌。炮阵联动不能为低价值火线牺牲安全的将或必要护卫。

护卫不是光环：处在我方炮与敌将之间的一枚士，可能恰好是危险的炮架。展开炮恰好隔一子时仍触发避炮。留守按正常行动完成并消耗当次加速额度，受阻、定身不擅自消耗。
