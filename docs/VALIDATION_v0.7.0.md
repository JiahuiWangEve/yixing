# v0.7.0 手绘山河地图

基线：`gpt` 的 `ace7c30564ea3027ecea701553608afbbc13566d`。恢复此前未提交的地图交互检查点后接入原始素材。仅更新地图呈现、输入与存档可靠性；16节点拓扑、每局8步、奖励池、营地升级、工坊删牌、据点减防、每战生命与消耗恢复等沿用 v0.6.0。下一版的牌组需求不在本提交内。

## 变化

- 原始纸本山河背景与八种军事地标，保留原文件 SHA-256。节点不再是圆形字母；地标布局不对称、间距不等，终点城寨位于右上。
- 道路只从真实图边生成。朱红表示当前可达，青墨表示走过，淡墨表示未行经。将／马／炮棋子和道路共享曲线函数。
- 点击／触摸先选中预览，确认出发后锁定重复输入，抵达才提交节点。取消不改进度；不可达节点可看说明但不能进入。
- 拖动地图不被解释成点击；取消触摸、第二触点、合成鼠标事件、Escape、窗口失焦及尺寸变化均有独立保护。
- 手机竖屏约显示3–4层，可拖动；桌面／横屏保留固定侧栏，竖屏保留固定底栏。按钮与地图交互区分离，回地图自动定位当前节点，另有「回到当前」。
- Web 在原有 ConfigFile／IndexedDB 存档之外同步写入同格式 localStorage 快照，避免抵达／结算后立即刷新读到上一次进度。行军途中刷新不会提前提交目标。没有云存档。
- 读档先验证格式、完整战斗字段、节点／路径索引及屏幕一致性；损坏存档拒绝恢复且不污染正在进行的局。兼容有效 v1 战斗、弃牌、战败与奖励状态。

使用原生窗口实际点击验证了首页→开局→地图→地标预览。首次出发、取消、正常胜利、调试跳过、重复奖励、多触点、三种身份、消耗牌与完整读档由自动回归覆盖。Web 单线程导出成功，使用已安装匹配的官方4.6.3模板。

## 发布时的 Web 检查

当前工作环境不允许直接启动独立浏览器测试进程，云浏览器也无法连接本地端口。因此把可复现的 `tests/browser_map_checks.py` 加入现有 GitHub Actions，在更新 `gh-pages` 前对真实 Web 导出进行四尺寸检查：触摸预览／取消／确认、重复确认、战斗刷新继续、调试胜利与奖励返回、曲线行军、事件刷新／结算、地图刷新继续。每尺寸9项存档状态断言，另检查脚本错误。完整截图与日志随该源码 SHA 的 Actions artifact 保存。

必须以精确提交对应的 Actions 成功结果、Pages 部署结果以及线上 `build-info.json` 的版本／source_commit／产物SHA-256 为发布完成依据。本文件本身不代替这些在线验证。
