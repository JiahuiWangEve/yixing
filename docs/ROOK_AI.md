# v0.12.0 车控线第一版

- 只看当前公开棋盘、角色与炮车姿态，不读手牌、牌库或未来玩家选择。
- 目标为玩家当前格与其实际免费移动可达格。马按马步并检查蹩腿；行军炮车检查两格直线中间阻挡；攻击姿态只有一格。可达落点若能以公开基础攻击威胁敌将，提高权重，而不是统计整张棋盘或所有九宫邻格。
- 车的射线到第一个阻挡为止。优先补上其他棋子尚未覆盖的出口；计算友军基线时移除被评估的车，避免挡住友车后把原有控制误认成新增控制。
- 控制质量相近时偏好较远落点，避免主动送进短剑/长枪范围；有真实收益时仍可接近。只对仍有用的旧线施加轻微留守/反折返偏好，过时线与真实挡枪救将可覆盖惯性。
- 可主动留守有效控线；留守不是被堵住，决战仍消费一次可用行动额度。冻结、攻击留位和完全堵路规则保持不变。
- 普通车选路按最终实际棋盘核算炮阵得失，避免第二个炮架挡炮或拆掉有效支撑。炮联合规划若借车作支援，扣除其独立控线机会成本，并保护其他已经成立的炮线。
- 只在敌方阶段计算，新增车评分计入现有 800 次阶段预算和每炮支援子预算；无逐帧搜索、无两步车绕障搜索、无双车联合规划。

## 本版追加：敌将躲已展开的玩家炮

玩家是攻击姿态炮车，且与敌将同线、恰好隔一子时，已轮到行动的敌将优先合法侧移脱线。九宫、阻挡、冻结与倒计时限制照旧。炮协同规划先预约这一步，不能再把将锁成炮架。没有安全步时不瞬移，也不额外获得行动。卡牌“展开”规则未修改。
