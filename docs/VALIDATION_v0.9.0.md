# v0.9.0 朱印军符行军图验证

基线：已发布的 v0.8.0 `1d5d33cc342a0c78926c44d12d094d31b5fc6003`。本版仅更换地图表现与对应点击区，不改变16节点、8步章节、边连接、奖励／战斗、卡牌、Space快捷键或存档结构。v0.8.0当前局可继续。

## 表现

- 7类透明黑色木刻SVG；类别文字始终显示。中国城门，不采用西式城堡／羊皮纸边饰。
- 红帅标记我方位置；已完成节点盖透明“将军”朱印。0.42秒落印后保持静态；从存档读取不重播动画。
- 清淡中性纸底与少量纤维；独立山、水、田线由节点／标签／朱印／道路保护区之外的留白确定。随机种子与布局不变时位置稳定，滚动不重排。空间不足就不绘制。
- 当前可达为深墨箭头与下划线，已走路线实线，其余浅墨虚线；选择为四角框。颜色之外仍有状态区分。
- 道路避让图标、文字和已落朱印。没有白底贴纸；原黑色图标仍保留。
- 缩小地图点击区并微调一个节点纵向位置，修正旧版相邻点击区重叠；图的连接关系不变。

## 本地验证

Godot 4.6.3标准版。最终 `bash scripts/verify.sh` 资源导入、所有游戏脚本解析、主场景120帧启动通过，31,027项断言通过：既有30,283项＋朱印地图744项。

新增专项覆盖四尺寸16节点点击区不重叠／不越界、装饰确定性与碰撞避让、预览／取消／行军不提前盖印、战斗／事件完成时落印、保存恢复仅保留静态印、重开局不泄漏状态。既有卡牌／教学／快捷键／存档安全套件全量保留。

最终日志见 `verification/v0.9.0/headless/`。验证过程中清理了编辑器指向临时渲染场景的缓存引用；最终资源导入没有错误。

## 原生渲染

云端Godot编辑器真实OpenGL Mesa llvmpipe渲染，四尺寸1280×940、390×844、844×390、360×640，40张截图与108项捕获／状态断言。包括地图、选择、战斗、落印开始／中间／静止、行军、事件、顶部决战预览和牌组。

目视检查黑符类别、朱印文字／透明底、红帅、窄屏固定面板、横屏朱印路线避让。仓库保留4张代表截图及JSON报告，其余同次截图留于验证工作区。复现脚本为 `tests/render_seal_previews.gd` 与同名场景。

## Web与发布

匹配4.6.3模板的单线程Web导出。精确源码SHA须经现有GitHub Actions全量检查和四尺寸真实Chromium流程后才能更新gh-pages。浏览器测试继续覆盖36项地图／续局状态检查与3项Space／Enter键盘检查。CI报告为本次验证，不把原生截图当作Web已通过。

随后通过GitHub App提交发布标记触发Pages，并校验线上build-info版本、源码SHA、完整pck／wasm哈希。在线结果以对应提交的Actions／Pages记录和最终发布回执为准，本文件不预先宣称尚未执行的在线检查。

## 限制

未在实体Android／iOS硬件验收触控和音效；没有新增敌人、精英规则或关卡。美术替换未要求删除当前存档，因此保持v0.8存档键和schema2，不迁移旧版。
