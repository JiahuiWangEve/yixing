# v0.11.0 炮阵协同

## 行动相序与公平性

1. 敌方阶段先统一判定攻击和受击撤退，再计算全军倒计时、冻结与加速资格。
2. 按最新棋盘进行阶段内联合规划，允许炮先走或支援先走；每一步执行前再次校验合法落点。
3. 完成全军正常动作后，才执行普通精英规则明确授予的额外一步。该步仍须有合法落点，不额外攻击，不再递归触发额外步。决战不进入此队列。
4. 玩家回合只显示现有攻击范围、倒计时和抖动，不预先计算或展示移动目的地。AI只读取公开位置、角色和姿态，不读取手牌、牌库或未来随机结果。

主动留守与受阻不同：有合法移动但选择维持有效炮阵，是完成一次正常行动，重置倒计时，若本次有可用加速则消耗一次。冻结、完全堵住及攻击留位不消耗加速。主动留守不累计“成功移动”次数，不触发普通精英额外步。决战仍每敌方阶段最多移动一次，剩余加速顺延，镇四方延迟不变。

## 战术评估

- 炮必须正交移动，路径不能越过任何棋子或玩家；形成炮击必须恰好一个炮架。
- 单炮可以与一个已就绪支援协同换位或留守。搜索两种合法顺序；支援一经预约不能再被另一炮预约。
- 优先直接威胁玩家，并评估玩家公开基础移动可达格、靠近敌将一侧的进攻/撤离格。单纯存在远处炮架没有高奖励。
- 将面临正交两格基础长枪走廊时，真正挡在中间的棋子具有优先价值；邻接或斜向不能用不存在的屏障“救将”。炮车玩家不套用这项挡枪奖励，避免反而提供炮架。此项不宣称能阻止一切卡牌效果。
- 稳定炮架比未预约的即将移动棋子可靠。临时木桩的剩余寿命、冻结、真实倒计时、决战加速余额和延迟均进入下一阶段预测。
- 当前阶段无法建立有效炮阵时，有限前瞻下一敌方阶段：炮单独转移、支援建立炮架，或二者再次联合移动。已经可攻击的预测棋子不同时被当成下一阶段移动者。所有预测下一阶段都重新规划，不锁定玩家上一回合的位置。
- 玩家绕到敌将后方时，过时的前线炮阵失去价值，炮会重新寻找有效侧翼。小收益不鼓励立即折返；原炮线失效或明显战术收益可覆盖惯性。两次历史位置随快照进入撤销、保存和续局。
- 多炮重叠覆盖有折扣，鼓励照看不同通道；未预约棋子随后移动时也评估是否破坏已有有效炮阵。

## 搜索上限与边界

只在敌方结算运行，不参与地图绘制或玩家拖动。每阶段最多规划4门炮，每炮最多3名当前支援，使用有限候选和目的地去重。双顺序产生的同一阵形只评分一次。阶段最多800次阵形评分；候选构建循环也在配额耗尽时停止。已有有效直攻阵形不再做多余前瞻。下一阶段先为各保留炮位进行单子预测，再给领先方案分配小规模联合扩展。

这是启发式有限搜索，不是全局最优解，也不预测玩家未来选择、受击后的随机撤退或所有精英额外步的最终落点。额外步按实际棋盘单独重算；失败方案安全回退，不增加行动次数。超过4门炮的非常规局面由合法单步评估处理。
