# v0.10.0 · 军阵与敌方规则

## 固定节点与血量

地图生成时确定每个战斗节点的阵型与特殊规则；查看、取消、选择另一条路线或战斗随机数变化都不会重掷。
普通战按地图区域挑选阵型，早期精英池为过河架炮、车卒压线、马后藏炮；后期加入士象固宫、两翼合围。章末为九宫决阵。难度不随玩家已经打了多少战斗而上涨。

所有敌马（包括增援）2血，象3血；普通将3血，精英将5血，Boss将9血。关隘仍只削弱章末将1血，显示9→8；不影响普通和精英将。

## 棋子与合作

- 士：九宫内斜向一格，不能越宫或穿子，1血。
- 急行卒：卒字旁标“疾”；1血，每敌方阶段可正常移动一次；过河前只能向前，过河后可横移，不能后退。
- 象不过河且可塞象眼，马受蹩腿限制，炮移动不越子、攻击恰好隔一子。
- AI只在规则引擎提供的合法步中评分。卒帮助炮形成炮架，过河卒使炮倾向跟进；马也能维持炮架，车偏向卒的邻线，士象偏向守将及覆盖将前通道。
- 仍然先统一判定攻击，再执行倒计时归零的移动。移动形成的新攻击线不会在当阶段额外攻击。

## 精英规则

| 阵型 | 规则 | 行为 |
|---|---|---|
| 车卒压线 | 连步压线 | 标记卒每第二次实际成功的正常行动，多执行一次合法移动。堵住、定身或攻击留位不计数；额外移动不再累计正常次数。 |
| 马后藏炮 | 援马驿站 | 第5、10、15敌方阶段结束后尝试增援。第4、9、14阶段结束时预告固定后排入口（左、右、左）。入口被玩家/敌子/桩占用或已有2匹活着的增援马，该波跳过，不积压。出生当阶段不攻击、不移动、不减倒计时。 |
| 过河架炮 | 渡河急炮 | 旗卒首次实际过河后，绑定UID的炮从下一敌方阶段起，在下一次成功正常移动时多走一步，仅一次。旗卒过河前被杀则不触发，炮死亡不会转给其他棋子。 |
| 士象固宫 | 九宫轮防 | 每阶段开始锁定轮值的存活士/象；只有该守军倒计时正常到点并成功移动时，才多走一步。不是提前行动，也不是无敌。 |
| 两翼合围 | 残阵反扑 | 敌将首次受到正伤害且存活时，标记当时存活的士/象/卒，令它们下一次成功正常移动多走一步。不会在玩家出牌中途行动，后续受伤不重复触发。 |
| 九宫决阵 | 九宫轮防＋残阵反扑 | 两规则显式展示；同时触发最多额外一步，不递归连动。 |

所有额外步重新计算当前棋盘合法步，不夹带额外攻击；若正常移动成功但额外步无合法落点，一次性加步仍消费。倒计时未到、定身、攻击后留位或无正常合法步则不消费待用的一次性效果。

## 界面、存档与测试

地图预览显示阵型及主规则；战斗桌面侧栏列明细则，手机“军阵”弹窗可查看完整说明。援军入口提前标记；轮防守军有圈标，急行卒有“疾”，旗卒有“旗”，加步标记为“+”。大于3血使用数字，不把9个血点横铺到相邻格。

战斗遭遇计数、绑定UID、待用加步、已触发反扑、增援入口、随机数全部进入撤销与续局快照。v0.10使用独立Demo存档schema3及命名空间；旧局不迁移，不删除旧浏览器数据，不重置角色解锁或设置。升级后需新开局。

教学/旧六关调试仍保留原第三关每三阶段援马练习，与山河节点的新精英规则完全隔离。

新规则回归见tests/enemy_encounter_checks.gd；继续运行既有完整验证、字体子集缺字与轮廓检查、Web包资源预算及四尺寸实际浏览器流程。无实体手机帧率/音效验收时明确不将模拟视口测试称为实机验收。

## 玩家回合后才决定敌方移动

抖动与倒计时只表示敌子即将行动。点击/悬停保留棋子规则、生命、倒计时及当前攻击范围，不显示下一落点或路径，不以未来攻击范围泄露目的地。

敌方阶段先按当前棋盘统一结算攻击/受击撤退；随后逐个执行到期敌子的移动，每个敌子使用当时最新玩家位置、先前移动棋子的占位和当前炮架重新求合法步并评分。额外步也重新计算。旧intent字段仅为无效兼容占位，不参与决策；警告刷新不消耗随机数。撤销重放恢复RNG后得到相同结果，不恢复旧路线决策。
