# 随机地图 v0.14.9

## 玩家能依赖的路线规则

- 每章实际走9个节点，含开场普通战与末尾决战。分叉有2–3条候选，经过1–3个节点汇合。
- 决战前4–5场战斗，计入开场和关隘；包含决战总共5–6场。
- 第一章至多1个关隘，第二章至多2个且不连续；至少有一条完全不经过关隘的路线。
- 每条路线都有可用构筑节点，决战前固定提供休整或工坊选择。休整仍是删牌或下一战初始多抽2张，不回血。
- 同一条路线相邻两场战斗不使用相同敌阵模板，即使中间隔了非战斗节点也不重复。没有新增或强化敌人。
- 所有节点都能从入口抵达并继续走到决战，没有孤立节点或死路。分支在类别上有真实区别，连线不交叉。
- 关隘四选一，优先3专属+1公共，全部是不同种类，不足时从合法池补足；普通战和决战仍三选一。无奖励的课后作业仍无普通奖励。

## 生成和保存

`route_generator.gd` 先生成有向无环逻辑图，再确定敌阵、奖励和奇遇；验证所有完整路径后才交给地图投影。最多尝试16次，失败使用另外验证过的保底图。保底同样使用现有敌阵，不复制或改变战斗规则。

拓扑、敌阵、奖励、奇遇类型、行商牌、强化随机、布局与装饰使用独立种子域。三种奇遇按独立均匀抽样决定，不为路线保底而修改概率。地图保存实际生成结果、生成器版本及稳定节点ID，读档、切回地图、旋转设备不会重新生成。节点仍只能结算一次。

本版存档为独立v0149键、格式6；旧demo局不迁移。不会清除声音、调试设置或角色解锁。生成器的完整玩法校验用于新图；读档另外校验结构、敌阵、物品与行军记录的一致性，不重抽或修改已保存内容。

## 布局与交互

先按照层和通道排布地标，轻微扰动避免机械整齐；节点、文字、通关印和道路都预留安全区域。最后按装饰种子在剩余留白放置已有山形、树田、水纹，放不下就省略。背景仍在最底层绘制，不遮挡黑印和红印，不新增生成图片。

道路几何和装饰缓存复用，滚动不会重算地图。旋转时保留视野中心的相对位置及原选择，而不是跳回当前节点。顶部留白保证决战图标完整；触摸区不重叠且至少44物理像素。右上查看牌组仍独立，关闭恢复选择和滚动。

悬停或原地长按只查看路线性质，不提前揭晓敌阵和具体奇遇。单击选中，再次点击同一可达节点出发，无双击时间限制；拖动或长按松手不出发。

## 回归入口

- `tests/route_generator_checks.gd`：多种子、每条路径、保底图、错误结构和种子独立性。
- `tests/random_map_ui_checks.gd`：四尺寸触摸/印章边界、装饰避让、缓存、旋转、牌组返回和存档不变。
- `tests/map_interaction_checks.gd`：滚动、两次点击、长按、节点选择和多种子布局。
- `tests/elite_reward_checks.gd`：奖励种类和权重、四尺寸全部选项、只领取一张、存档及无奖励流程。

既有事件、第二章、棋盘和浏览器套件使用相同生成图的稳定节点ID定位，不再假设固定16节点或决战ID15。测试专用事件准备只配置合法节点，不在生产代码添加测试开关。
