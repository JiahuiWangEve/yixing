# 弈行 v0.8.0：四张永久起始牌组与卡牌重平衡

## 起始牌组不是起手抽牌数

| 身份 | 生命 | 四张永久起始牌 | 免费行动 |
| --- | --- | --- | --- |
| 将／帅 | 2 | 短剑×2、长枪×1、续命×1 | 正交1格 |
| 马 | 1 | 短剑×2、长枪×1、进击×1 | 马步，遵守蹩马腿 |
| 炮车 | 1 | 短剑×1、架炮×1、炮击×1、展开×1 | 行军正交1～2格／攻击正交1格 |

普通初始手牌仍为0张。临时免费移动牌单列，不计入四张永久牌组、不计入6张手牌上限。每回合基础3能量；成功免费移动或普通移动牌抽1张；结束回合不自动抽牌，手牌跨回合保留。每回合一次免费行动、一次普通移动牌额度，攻击附带位移不占这两种额度。生命上限5，跨战保留。教学保持独立预设，不冒充新局牌组。

## 奖励

每次提供两张不同的当前身份专属牌和一张公共牌，三选一；保留删一张与跳过。所有地图节点、普通奖励和调试预选奖励共用相同规则。炮车姿态不改变奖励池。

| 奖励池 | 卡牌 |
| --- | --- |
| 公共 | 短剑、长枪、斜斩、调息（消耗） |
| 将 | 续命、横扫、流血、震退、吐纳、镇四方、固守、踏马 |
| 马 | 疾行、追斩、进击、回马枪、马踏连营、连袭 |
| 炮车 | 架炮、炮击、展开、转进、机关炮架、装填 |

马池按不放回加权选择：疾行权重1，其余每张权重2。该权重表示每次抽选的相对权重，不是最终出现概率恰为一半。所有其他牌池同权。退敌、定身符不进入新牌组或新奖励；换位不再进入马奖励；踏马只属于将奖励。没有新增侧击。

## 将的变化

- 镇四方：3费，先抽1张，再使正交相邻的全部敌子移动倒计时+2。没有伤害，不改变敌方攻击能力，不消耗；抽牌导致超限时也先完整结算，再进入弃牌。
- 固守：2费，消耗。到下个玩家回合开始前，抵挡下一次实际受击。该次不掉生命、不受击转移；多个攻击者中只抵挡一次。未触发也到期失效；重复打出刷新为一次，不叠加次数。
- 震退：仍为1费1伤，选择自身周围3×3的8个邻格或正交距离2格的一个敌子，不是群伤。沿玩家到目标的符号方向再推1格；目标斜向则斜向推。边界或占用阻止推移但不取消伤害。扩大的是可选目标区域，不新增直线遮挡条件。
- 流血：原贯刺保留内部存储ID，改名并改为1费。选一个正交相邻敌子挂2点延迟伤害，完整结算敌方攻击、移动、增援、木桩计时后，到下个玩家回合开始结算。跟随敌子身份，不跟随原格子；同目标多次施加伤害相加，提前死亡不转移给其他目标。若玩家先死亡则不再结算；延迟击败将立即胜利，不继续玩家回合操作或重复奖励。
- 横扫：仍为2费，每个目标1伤，范围改为以玩家为中心的3×3全部8个邻格。不可伤害木桩。
- 踏马：1费，按原马步移动与蹩腿规则，成功抽1张，使用普通移动牌额度。
- 吐纳保持3费、消耗；下回合起连续3个玩家回合各+1能量。重复使用延长3回合，不叠加每回合增量；过关清除。

营地仍只升级短剑与长枪，不扩大原营地功能；横扫与流血没有新增升级卡。

## 马：连袭与位移计数

连袭2费，在自身周围3×3的8邻格中只选择一个敌子，造成1＋本回合此前成功主动位移次数的伤害，不是群伤或第二次攻击。卡面与展开预览实时显示当前伤害。

免费移动、疾行／踏马等移动牌、进击／回马枪／马踏连营等攻击附带的实际位移都计入；一次成功行动计一次，不按走过格数计。失败移动、空点、未击杀而未位移、切换姿态、受击转移不计。新玩家回合清零。计数随悔棋与存档恢复。

原攻击不变：进击1费、正交相邻1伤、击杀后进入目标格；回马枪1费，先沿目标反方向退1空格再造成1伤；马踏连营2费，遵守蹩腿的马步攻击1伤，击杀后进入目标格。三者不额外抽牌，不占免费／移动牌额度。

## 炮车

每战以行军姿态开始。展开1费消耗，行军→攻击，每回合首次展开抽3张；完整抽完后处理6张上限。转进0费，攻击→行军，不抽牌、不刷新免费移动额度。没有固定收炮按钮。攻击姿态仍能免费正交走1格并抽1张；行军能正交走1～2格。切换姿态本身不计主动位移。

炮击必须同一行列且恰隔一子：行军2费1伤，攻击1费2伤。

- 架炮保持1费，在曼哈顿距离1～2的空格放木桩，持续3个敌方阶段，第三阶段后消失。
- 机关炮架1费，消耗，放桩合法范围与架炮完全一致。木桩持续到本场战斗结束，不递减寿命；显示∞，挡路与充当双方炮架的规则不变。
- 装填1费，本回合下一张成功打出的炮击伤害+1，若这发击杀则抽1张。未成功的目标选择不消耗装填，其他攻击不消耗或受益。未使用则回合结束失效，重复使用只刷新一发。两种姿态均适用，卡面实时更新伤害。

## 消耗与状态

续命、调息、展开、吐纳、固守、机关炮架为消耗牌：每个实体副本成功使用后本战移除，下一战从永久牌组恢复。超限弃牌不等于使用，仍可回收；无效动作不消耗。悔棋恢复牌、护盾、位移次数、延迟队列、装填、敌子身份、计时和随机状态。新战与战斗结算清除新临时状态。

## Demo存档换版

按本版确认，取消旧存档兼容。v0.8.0使用独立的`route_run_v080.cfg`／`yixing.route_run.v080`和schema2，不读取或迁移旧局；需开始新征途。退敌、定身符、换位的卡牌定义与执行分支已删除，教学奖励也不再引用它们。仍保留既有投石教学卡及短剑／长枪升级。
