# 弈行 v0.15.3：起始牌组、身份与奖励

## 起始牌组不是起手抽牌数

| 身份 | 生命 | 四张永久起始牌 | 免费行动 |
| --- | --- | --- | --- |
| 将／帅 | 5/5 | 短剑×2、长枪×1、续命×1 | 正交1格 |
| 马 | 3/3 | 短剑×2、长枪×1、进击×1 | 马步，遵守蹩马腿 |
| 炮车 | 3/3 | 短剑×1、架炮×1、炮击×1、展开×1 | 行军正交1～2格／攻击正交1格 |

普通初始手牌仍为0张。临时免费移动牌单列，不计入四张永久牌组、不计入6张手牌上限。每回合基础3能量；成功免费移动或普通移动牌抽1张；结束回合不自动抽牌，手牌跨回合保留。每回合一次免费行动、一次普通移动牌额度，攻击附带位移不占这两种额度。将生命上限5，马与炮车上限3，跨战保留；长生玉玺解除将的生命上限。教学保持独立预设，不冒充新局牌组。

## 桌面快捷键

空格键结束玩家回合，Enter／小键盘Enter不再结束回合。按键松开与系统长按重复不触发；动画、弃牌、奖励、首页与其他非战斗界面不可借空格跳过。地图可达节点单击进入，长按仅查看信息。

## 奖励

普通战斗提供两张不同的当前身份专属牌和一张公共牌，三选一；精英尽量提供三张专属与一张公共，四选一。均可跳过，不再战后删牌。所有地图节点、普通奖励和调试预选奖励共用相同规则。炮车姿态不改变奖励池。

| 奖励池 | 卡牌 |
| --- | --- |
| 公共 | 短剑、长枪、斜斩、调息（消耗） |
| 将 | 续命、横扫、流血、震退、吐纳、镇四方、固守、踏马、空投、血锋、浴血破阵、背水斩 |
| 马 | 疾行、追斩、进击、回马枪、马踏连营、连袭 |
| 炮车 | 架炮、炮击、展开、转进、机关炮架、装填 |

马池按不放回加权选择：疾行权重1，其余每张权重2。该权重表示每次抽选的相对权重，不是最终出现概率恰为一半。所有其他牌池同权。退敌、定身符不进入新牌组或新奖励；换位不再进入马奖励；踏马只属于将奖励。没有新增侧击。

## 将的变化

- 凯旋：每场战斗胜利回复1命，上限5。无常规奖励的战斗也生效，跨章/最终Boss同一结算，不额外叠加；教程不触发。初始5命，4张永久初始牌不变。
- 血锋：1费，自损1命。选正交方向，连续3格内所有敌人各2伤，穿透敌人，不移动、不消耗；点该方向1–3格内任一格选方向，有敌人才能使用。
- 浴血破阵：3费，消耗，自损1命。四正交各2格内所有敌人各3伤，最多8格不含斜角；不移动、不跳过回合。
- 背水斩：1费，正交相邻单敌1伤，出牌时恰好1命则3伤；不自损、不消耗。
- 上述自损不被护盾抵消，不触发受击转移。1命可使用，自损至0立即判负，优先于敌将击倒和凯旋。固定3费弃置补抽不触发卡牌效果。

- 镇四方：3费，先抽1张，再使正交相邻的全部敌子移动倒计时+2。没有伤害，不改变敌方攻击能力，不消耗；抽牌导致超限时也先完整结算，再进入弃牌。
- 固守：2费，消耗。到下个玩家回合开始前，抵挡下一次实际受击。该次不掉生命、不受击转移；多个攻击者中只抵挡一次。未触发也到期失效；重复打出刷新为一次，不叠加次数。
- 震退：仍为1费1伤，选择自身周围3×3的8个邻格或正交距离2格的一个敌子，不是群伤。沿玩家到目标的符号方向再推1格；目标斜向则斜向推。边界或占用阻止推移但不取消伤害。扩大的是可选目标区域，不新增直线遮挡条件。
- 流血：1费，选一个正交相邻敌子。本玩家回合末与下一玩家回合末、敌方攻击前各扣1血；目标身份绑定，不随格子，多次施加各自结算两次。目标死亡则剩余失效，不继承给复归守军。击败将立即胜利，不再启动敌方阶段；空投休整也正常结算流血。
- 横扫：仍为2费，每个目标1伤，范围改为以玩家为中心的3×3全部8个邻格。不可伤害木桩。
- 踏马：1费，按原马步移动与蹩腿规则，成功抽1张，使用普通移动牌额度。
- 吐纳保持3费、消耗；下回合起连续3个玩家回合各+1能量。重复使用延长3回合，不叠加每回合增量；过关清除。

工坊可强化一张符合注册规则的牌或删除一张永久牌，二选一。休整可删牌、回复1命或随机获得一张本角色合法永久牌，三选一。强化仍仅支持短剑与长枪；横扫与流血没有新增升级卡。

## 马：连袭与位移计数

连袭2费，在自身周围3×3的8邻格中只选择一个敌子，造成1＋本回合此前成功主动位移次数的伤害，不是群伤或第二次攻击。卡面与展开预览实时显示当前伤害。

免费移动、疾行／踏马等移动牌、进击／回马枪／马踏连营等攻击附带的实际位移都计入；一次成功行动计一次，不按走过格数计。失败移动、空点、未击杀而未位移、切换姿态、受击转移不计。新玩家回合清零。计数随悔棋与存档恢复。

原攻击不变：进击1费、正交相邻1伤、击杀后进入目标格；回马枪1费，先沿目标反方向退1空格再造成1伤；马踏连营2费，遵守蹩腿的马步攻击2伤，击杀后进入目标格。三者不额外抽牌，不占免费／移动牌额度。

## 炮车

每战以行军姿态开始。展开1费消耗，行军→攻击，每回合首次展开抽3张；完整抽完后处理6张上限。转进0费，攻击→行军，不抽牌、不刷新免费移动额度。没有固定收炮按钮。攻击姿态仍能免费正交走1格并抽1张；行军能正交走1～2格。切换姿态本身不计主动位移。

炮击必须同一行列且恰隔一子：行军2费1伤，攻击1费2伤。

- 架炮保持1费，在曼哈顿距离1～2的空格放木桩，持续3个敌方阶段，第三阶段后消失。
- 机关炮架1费，消耗，放桩合法范围与架炮完全一致。木桩持续到本场战斗结束，不递减寿命；显示∞，挡路与充当双方炮架的规则不变。
- 装填1费，本回合下一张成功打出的炮击伤害+1，若这发击杀则抽1张。未成功的目标选择不消耗装填，其他攻击不消耗或受益。未使用则回合结束失效，重复使用只刷新一发。两种姿态均适用，卡面实时更新伤害。

## 消耗与状态

续命、调息、展开、吐纳、固守、机关炮架为消耗牌：每个实体副本成功使用后本战移除，下一战从永久牌组恢复。超限弃牌不等于使用，仍可回收；无效动作不消耗。悔棋恢复牌、护盾、位移次数、延迟队列、装填、敌子身份、计时和随机状态。新战与战斗结算清除新临时状态。

## Demo存档换版

按本版确认，取消旧存档兼容。v0.8.0使用独立的`route_run_v080.cfg`／`yixing.route_run.v080`和schema2，不读取或迁移旧局；需开始新征途。退敌、定身符、换位的卡牌定义与执行分支已删除，教学奖励也不再引用它们。仍保留既有投石教学卡及短剑／长枪升级。

当前版本照常保存与续局，缺失字段、非法身份、重复敌子ID或损坏状态会被拒绝，且不污染当前运行。找不到当前版存档时，首页明确提示“v0.8.0 旧局不续用，请开始新征途”。不删除浏览器旧数据、不清空其他存储，也不修改身份解锁、声音偏好。

## v0.14.1 将专属奖励：空投

3费、消耗，不加入初始牌组，加入将的专属奖励池（含使用同池的行商）。选择棋盘任意其他空格降落，不能落在敌子、木桩或本人原格；落地周围3×3所有敌子各受3伤，不伤木桩。自身扣1命，不触发固守或受击撤退；只剩1命也允许使用，生命归零优先失败，即使同时击杀敌将，不会先发放胜利收益。

使用当回合仍可继续行动，空投不额外抽牌、不刷新已有移动额度，成功落地计1次主动位移。下一个玩家回合不能主动移动或出牌，点击“跳过回合”或按空格结束；敌方、流血、疲惫、吐纳、复归与增援仍正常结算。再下回合恢复行动。跳过状态随保存/悔棋一致恢复，战斗结束清除，不延续到下一关。多张空投分别消耗、下一战恢复，不因同回合连用累加休整回合。

## v0.14.5 战斗内过牌

统一支付3费，将一张手牌弃置，不触发牌效，然后正常抽1张，不占用移动牌或免费移动额度。0费牌与临时免费移动牌过牌也统一支付3费。消耗牌并未打出，因此仍进弃牌堆循环；免费移动牌只移除当前临时牌、不进弃牌堆，也正常抽1张，但不重新生成免费移动牌。先移除再抽，遵守手牌上限；空抽牌堆按原规则洗入弃牌堆，可能抽回刚弃的牌。费用不足、敌方行动动画、教学或规则弹窗、空投休整回合禁止过牌。疲惫已经扣除的费用不返还；补抽到疲惫立即再扣1能量，最低0且不欠费。永久牌组不变，支持保存与悔棋。手机明确向右拖入内缩侧区高亮后松手，拖回或触摸取消不确认；起点与侧区重叠时轻微上拖不会误弃；桌面和手机选中牌或按住拖动时均显示同一右侧弃置区，点击该区或拖入松手确认，无重复底部按钮。

## v0.14.5 声音设置

首页“设置”进入独立设置页，目前只有声音开关与返回首页；Esc也返回首页。其他页面不再有直接声音按钮。声音偏好独立持久化，不随新局、继续或悔棋改变；旧设置没有声音字段时默认开启。调试模式开关仍保留首页，默认关闭。
