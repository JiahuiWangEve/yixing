# 弈行 v0.5.3：开局、专属牌组与消耗

基线：main 的 v0.4.4 恢复工程（9897ef4）。本次规则由 2026-10-20 的开局设计讨论确认。

## 开局与构筑

| 开局 | 生命 | 免费行动 | 8张初始牌 |
| --- | --- | --- | --- |
| 将／帅 | 2 | 正交走1格 | 短剑×3、长枪×2、踏马、续命、定身符 |
| 马 | 1 | 马步，遵守蹩马腿 | 短剑×3、长枪×2、疾行、追斩、定身符 |
| 炮车 | 1 | 行军正交1～2格／攻击正交1格，不穿透 | 短剑、长枪、疾行、架炮、炮击×2、展开、转进 |

维持每回合基础3能量、0张普通起手牌、移动成功抽1张、结束回合不自动抽牌、普通手牌上限6、手牌跨回合保留；每回合一次免费行动和一次移动牌额度。移动牌增加可选落点，不增加每回合移动牌次数。生命跨关保留，上限5；新关卡重置手牌与临时状态，并按永久牌组重新洗牌。

每次加牌奖励提供两张不同的专属牌和一张公共牌，再随机排序。身份决定奖励池，炮车姿态不影响牌池；各关可重复获得同名牌。保留加牌、删牌、跳过。

| 奖励池 | 卡牌 |
| --- | --- |
| 公共 | 短剑、长枪、斜斩、退敌、定身符、调息 |
| 将 | 续命、横扫、贯刺、震退、吐纳 |
| 马 | 疾行、换位、追斩、进击、回马枪、马踏连营 |
| 炮车 | 架炮、炮击、展开、转进 |

将默认可用；原有六关通关记录同时解锁马和炮车，兼容 `skill_unlock.cfg` 中的 `horse_unlocked`。调试选关可以直接选择任意身份，不要求先解锁，预选奖励也使用对应身份牌池。原五节教学保持独立的1命预设与原牌组；开局选择页与游戏内提示解释炮车。

## 炮车

每关以行军姿态开始。行军可免费正交走1或2格，途中和落点需为空，不能移动吃子。攻击姿态可免费正交走1格；普通移动牌仍按卡面执行，消耗原移动牌额度。

| 行动 | 费用 | 效果 |
| --- | --- | --- |
| 展开 | 1，消耗 | 行军→攻击；每回合首次进入攻击姿态抽3张牌 |
| 转进 | 0 | 攻击→行军，不抽牌，不刷新也不消耗已有移动额度 |
| 炮击 | 行军2／攻击1 | 两种姿态均要求同一行列且中间恰好一子；行军1伤，攻击2伤 |
| 架炮 | 1 | 沿用原两格曼哈顿距离内空位放桩、持续3个敌方阶段的规则 |

同回合反复切换仅首次展开抽牌；保持攻击姿态跨回合不自动抽牌。完整抽完3张后，如超过6张，持续要求弃牌直至6张。牌库不足时沿用弃牌堆回收规则，全部耗尽则尽可能抽取。已为攻击姿态时不能使用展开，行军姿态不能使用转进。短剑、长枪等公共攻击两种姿态可用。

木桩挡路且可被双方炮利用；放桩目标预览若造成玩家处于威胁中会标红。木桩不能被普通攻击选为伤害目标。受击安全撤退不抽牌，保留炮车姿态。

## 消耗

统一属性：续命、调息、展开、吐纳带“消耗”标签。每张实体副本每关只能成功使用一次；成功使用后不入弃牌堆，下关从永久牌组恢复。同名两张可各用一次。手牌超限弃掉的消耗牌仍可洗回；条件或能量不满足不消耗。撤销会恢复牌和效果。

## 吐纳

将专属奖励，3费，消耗。当回合不返还能量；下回合起，连续3个玩家回合以4能量开始。重复使用每张延长3回合，增量仍为1，不累加为5或更多基础能量。额外能量不限制调息等即时能量来源。跨关清除；界面区分当前回合加成和后续剩余回合。撤销恢复计时、能量、牌序与随机状态。

## 实现与验证入口

配置：`game/start_profiles.gd`；核心：`game/main.gd`；消耗元数据：`CONSUMABLES`；快照：`game/undo_history.gd`；规则回归：`tests/recovered_checks.gd`、`tests/start_profile_checks.gd`。

执行 `bash scripts/verify.sh`。Web使用Godot 4.6.3单线程模板导出。持续源码分支为 `gpt`，发布产物分支为 `gh-pages`，不直接修改 `main`。仅发布分支保留Web产物；源分支不提交引擎、模板、存档、缓存或 `build/`。

## 马的攻击位移

- 进击：1费，正交相邻目标1伤，击杀后进入目标原位置。
- 回马枪：1费，选正交相邻目标，沿目标反方向后退1格，再造成1伤；退路必须在棋盘内且为空，未击杀也后退。
- 马踏连营：2费，按马步选择敌子，遵守蹩马腿，造成1伤；击杀后进入目标位置，未击杀留在原位。
- 三张均为可重复循环的攻击牌，只在马专属奖励池出现。位移不占免费或移动牌额度，不抽牌；支持威胁预览与撤销。不可攻击木桩。
- 炮击卡面费用和伤害随姿态即时变化，出牌费用、拖放验证同步使用当前姿态。

## 攻击姿态移动补丁

攻击姿态的免费行动牌改为“炮步”：正交移动1格，移动抽1张；行军仍为正交1～2格。不能落在占用格。两种姿态共用每回合一次的免费行动，切换不刷新次数。普通移动牌继续按卡面规则执行。

固定“紧急收炮”能力和独立按钮已移除。使用0费“转进”卡切回行军姿态，不抽牌，不消耗或刷新免费移动额度。
