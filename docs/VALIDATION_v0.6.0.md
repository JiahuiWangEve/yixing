# v0.6.0 山河棋路与战斗跳过

基于远端 gpt 的 c4ac6db（v0.5.3），保留炮车、马攻击、起始生命、跨战生命、姿态、移动与原奖励池规则。源码仍提交 gpt，Web 沿 gpt-web.yml 导出并发布到已有 gh-pages。

## 玩法

正常开始进入第一章：16个节点，8层，每局走8个节点含最终敌将。三次以上分支决策，分支后汇合，必经营地，无连续精锐。只允许沿边前进；当前可选节点深色，走过的线绿色，其他线路淡色。拓扑为手工稀疏模板；种子确定战场模板与每节点奖励，后续访问不重掷。战场继续复用原6个模板，精锐使用后期布局，BOSS使用第6关敌将体系。

- 营地：升级一张未升级短剑或长枪（伤害1→2，费用不变），或下一战初始抽1张；不支持的牌不会出现升级选项。
- 工坊：永久删一张牌，可删升级牌，空牌组可离开。
- 渡口事件：下一战初始抽1张，或获得一张长枪，或离开。
- 据点：破寨使本章BOSS敌将生命3→2；地图状态和选择文字可见。
- 整备效果不叠加，持续至下一场战斗；不改动现有生命初始化和跨战生命规则。
- 普通战与精锐保留加牌/删牌/跳过奖励，奖励完成后回地图；BOSS直接章节胜利并解锁马/炮车。
- 调试跳过在 play/discard 阶段调用正常胜利入口，取消选牌、拖动、动画锁，重复调用不会再次发奖。教程隐藏并禁止跳过，旧调试选关保持六关模式。

升级存放于每个牌组槽位的独立牌ID（sword_plus/spear_plus），抽牌、弃牌、洗牌、删除及战斗快照均保留这一值。同名未升级副本不受影响。升级版不加入奖励池。

地图状态独立于战斗撤销。地图结算后清除战斗快照、手牌、牌堆、敌人、能量、吐纳等临时状态；下场从永久牌组重建，恢复消耗牌。章节战斗胜利进入奖励时结束悔棋历史，避免跨节点撤销；旧六关模式仍保留胜利出牌撤销回归行为。

## 存档

沿用 ConfigFile 的 user:// 本地机制，独立 route_run.cfg；保存地图、种子、已走节点、待结算节点、牌组、身份、完整战斗快照与随机数状态。节点进入、奖励结算立即保存；战斗无动画锁时约每秒保存。首页「继续山河棋路存档」恢复。完成章节不会再次恢复奖励；新开章节覆盖旧存档。关闭页面可能丢失最后不到一秒的战斗操作，节点奖励不靠这个周期提交。清除浏览器存储会丢失本地进度；没有云存档。

## 首版限制

固定章拓扑；种子改变战斗模板与奖励，暂不提供输入种子的UI。支持短剑/长枪单级升级。非战斗节点无需战斗、无消耗资源，平衡仍待实际玩家试玩。没有完整围城、新AI、外交、粮草、宝物或巡逻系统。未进行真实手机触控和音效体验验收。
