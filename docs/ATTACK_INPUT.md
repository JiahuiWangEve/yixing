# v0.15.1 攻击交互与卡牌说明

## 展示

- `card_description.gd` 为手牌、永久牌组、商人、奖励、强化演出和图鉴提供共同说明。
- 仅手牌显式启用战斗上下文；当前费用、姿态、装填、长缨、位移次数与替命状态均只读查询，不触发结算。
- 小屏战斗详情精炼完整行动要点，图鉴保留全部补充规则。消耗限制按每张实体牌计算，不按同名牌合并。
- 临时移动不进入永久牌组，成功使用或弃置后消失，未用时回合结束消失；3费弃置仍按正常抽牌规则补抽1张。

## 合法行动

`attack_targeting.gd` 分离范围、可攻击敌子和唯一行动。淡框只表示可触及范围，强环表示实际可攻击的敌子；费用、炮架、挡路、蹩马腿、回马枪退路、教学步骤和战斗锁全部参与检查。预览不修改牌组、历史、能量或随机数。

- 单体：恰好一个合法敌子时可快捷使用；多个敌子必须明确指定。
- 横扫、浴血破阵：范围内有敌子时是一个自身中心行动。
- 血锋：按方向而非敌人数计选择；同方向多个敌子仍是一个行动，多方向需指定。
- 空投：必须显式拖到其他合法空格，永不自动选择落点。
- 明确瞄准失效敌子、木桩或无效方向时取消，不转打另一个目标。

## 手势保护

出牌只在松手时发生，重新验证实体牌UID、牌种、回合、费用和合法目标。需要明确移动超过28逻辑像素；向上快捷使用还须超出手牌区16像素。微拖、拖回、触摸取消、失焦、多指、动画、敌方回合和空投休息回合均不可提交。多指取消会吞掉所有尚未抬起手指的释放，不允许第三指重启。

右侧弃置区优先于攻击快捷使用，包括费用不足时也不得回退为出牌。手机长按拖牌、地图点击/长按、普通移动和数字键选择逻辑不改变。

## 验证

- 原生描述测试覆盖所有牌、四尺寸、密集手牌、消耗/临时语义、公式与宝物状态以及只读性。
- 原生攻击测试覆盖全部攻击类型、唯一/多目标、方向、落点、真实输入取消和每个现有保护。
- Web基础验证使用普通有效存档与真实鼠标/触摸事件；全量四尺寸回放在发布后后台执行。
