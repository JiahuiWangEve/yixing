# v0.9.1 验证

## 范围

仅字体子集与 Web 资源排除；保留 v0.9.0 黑红军符地图、v0.8.0 卡牌／空格操作与现有存档格式。未改敌方配置、引擎模板、托管、PWA或缓存策略。

## 本地验证

- `scripts/font_subset.py`：601 个码点，261,664 字节 OTF；逐字轮廓和 advance 与原始第 0 面相等，固定 fontTools 4.61.1 可重建。
- Corpus guard：原文、Unicode 转义、数字码点、完整 ASCII，拒绝未知动态码点表达式。
- Godot FontFile：1,207 项检查，关闭系统字体兜底后覆盖所有码点，逐字与代表性排版宽度不变。
- 原有完整回归：31,027 项通过；资源导入、全部脚本解析、主场景120帧启动通过。
- 原生四尺寸：40 张地图截图／108 项断言；52 张卡牌截图／40 项布局检查，零不完整预览。手机通关印画面与 v0.9.0 像素完全相同。
- Web 单线程导出：PCK **889,276 字节**，相比 v0.9.0 的20,452,880字节缩小约95.7%。本地gzip9为688,338字节；这不是服务端实测传输量。
- 导出PCK逐项MD5校验通过；不含原TTC与旧山水图，包含子集、许可、新军符和音效。

## CI 和线上验证

工作流对精确源码 SHA 重跑上述检查、PCK审计及真实 Chromium 四尺寸地图／键盘流程，并保留构建产物和截图。发布后须验证 build-info.json 的源码 SHA、完整PCK/WASM SHA256和服务端实际gzip传输字节；不能用本地结果代替线上完成声明。

## 限制

原生界面使用云端 Linux llvmpipe，不是实体安卓／iOS测试。未测用户设备首次启动耗时或听音；减小下载量不代表浏览器编译、网络延迟同比减少。全字体仍在源码用于重建，字体子集不适用任意用户输入／未来外部文案，新增文案必须重建。
