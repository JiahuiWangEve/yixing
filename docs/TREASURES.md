# 章间宝物（v0.15.0）

每次正式冒险击败第一章首领后，依次完成胜利盖印、常规卡牌奖励或无收益提示、课后作业复制牌交付，然后领取本职业三件宝物中的一件。点击即领取并进入第二章，不额外确认。待选及已领取状态都保存，重复点击或读档不能重复发放；教学不发放，正式局调试胜利走相同流程。每局只有一件，不是账号永久增益。

## 将
- 长生玉玺：取消生命上限。不立即回血、不增加初始生命，续命、药庐和凯旋均可超过5命。
- 替命金符：每战第一次命数归零改为1命，包括主动自损；不是护盾，不提供后续无敌，也不取消空投的下一回合休息。用过后再次归零仍失败。
- 行军虎符：每成功主动位移3次，获得额外0费临时将步，正交移动1格。累计余数跨回合保留，战后重置；这张额外将步本身也计入位移，受击撤退不计。与自动免费牌及移动牌额度独立。

## 马
- 追风蹄铁：每回合第2次成功主动位移立即获得1能量，每回合一次。
- 踏阵长缨：每回合第2次成功主动位移，使本回合下一张攻击牌整体伤害+2，每回合一次。取消、非法目标、弃置不消耗加成；回合末失效。回马枪先位移后攻击，可在当张触发；进击/马踏连营先攻击后击败位移，只增强下一张攻击。
- 饮泉玉勒：每战前2次真正击败敌子各回复1命，上限5；满血也消耗次数，不屈暂倒不算，击败敌将的回血可带到战后。

## 炮车
- 镇关炮印：以攻击姿态开始回合，且尚未主动位移或切换姿态时，本回合首次炮击减1费，最低0。反复切姿态不刷新。
- 游击轮轴：每回合首次从攻击切回行军，获得额外0费临时转移，正交移动1格，不占自动免费或移动牌额度。反复切姿态不重复发牌。
- 连珠火签：每次炮击真正击败敌子抽1张，无每回合次数限制。可与装填的击败抽牌分别触发，疲惫按每次抽取正常扣能量且不低于0。不屈暂倒不算；战斗已终结则不再进行战斗内抽牌。

## 临时牌、保存与界面

两张宝物移动牌使用不抽牌；使用后或回合末移除，不进入弃牌堆、永久牌组，也不在下场战斗恢复。按全局弃置规则仍花3能量并抽1张，不触发移动。卡牌保留独立实例ID，悔棋恢复宝物计数、临时牌和随机状态，但不会退还普通模式的悔棋额度。

地图图标只说明固有规则，不展示上一战计数。棋盘图标可显示必要进度、剩余次数或已用标记；长按或悬停查看完整状态。宝物选择使用独立纸面，无卡牌费用圆，不修改战斗或地图原有布局。

## 验证入口

- `tests/treasure_combat_checks.gd`：九件战斗效果、位移先后、救命与胜负优先级、临时牌和悔棋。
- `tests/treasure_route_checks.gd`：章间领取、无收益/课后作业、保存恢复、重复拒绝、生命上限与教程隔离。
- `tests/treasure_ui_checks.gd`：四尺寸布局、输入保护、图标只读及真实保存的浏览器测试数据。
- `tests/browser_treasure_checks.py`：导出 Web 的单击领取、读档、取消与滚动保护、图标浮窗；默认桌面/手机基础，`--full`覆盖四尺寸与九件宝物。
