## 真实渲染与发布门禁

当前工具沙箱阻止本地Chromium建立socket，因此该本地启动失败不算Web验证成功。CI在发布之前运行四尺寸地图基线，以及桌面/手机触摸视口的六类炮阵存档、动画截帧、无未来落点、Boss次数与RAF响应检查；任意失败将阻止发布。

使用正常浏览器环境的运行结果、实际截图及精确源码SHA由对应CI artifact提供。原生GUI另已完成24张真实截图、136项检查、0失败，包含桌面与手机视口的六类炮阵前后对照；独立native-render-report.json保留该结果。headless行为测试不等同原生画面验收。手机视口使用云端CPU，不等同实体手机性能。

## 性能边界

评分只在敌方阶段运行，阶段最多800次评分，不使用按时间提前退出以保持重放一致。常规四炮原生热身约27–31ms；4炮+9支援、每轮可动且3次加速的刻意高压场景约57ms，具体共享CPU测量会波动。正式Web另记录RAF最大间隔与输入至存档时间，不用原生数字替代Web数据。

CI通过后将核对公开build-info.json的版本/源码SHA，以及实际PCK与WASM的完整SHA-256，确认部署内容与同次构建一致。未完成的发布验证不在此提前标为通过。
