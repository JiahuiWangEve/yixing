## Web与发布门槛

最终代码使用匹配4.6.3模板成功导出单线程Web。本地工作环境无法直接启动独立浏览器进程，所以现有GitHub Actions对精确源码SHA再运行全部验证、导出与四尺寸真实Chromium触摸流程：预览／取消／确认、重复点击、防提前抵达、战斗刷新续局、调试奖励返回、行军、事件刷新／结算与地图刷新。测试读取本版新Web存档键。

CI通过后才提交导出到gh-pages，再通过发布标记触发Pages并核对线上build-info.json版本、源码SHA与pck／wasm哈希。在线结果以对应提交的Actions／Pages记录与实际线上校验为准，本文件不预先宣称尚未执行的在线结果。
