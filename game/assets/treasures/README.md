# Treasure icons: approved B variant

Nine transparent 128×128 PNGs proportionally downsampled with Lanczos from the matching original B-vermilion/png-384 RGBA sources. The original black-and-vermilion drawing is preserved without recoloring or redraw. No A assets, atlases, previews, 384px source files, or AI-generated replacements are included.

The JSON manifest records canonical game IDs, source filenames and dimensions, source SHA-256, output dimensions and SHA-256, and exact output byte sizes. The HUD remains 48 logical pixels within a 48×48 hit area; selection cards render the sharper assets at 96/104 logical pixels. Treasure names and rules remain in treasure_system.gd.
