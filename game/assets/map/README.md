# 手绘地图原始素材

本目录的两张 PNG 是用户确认采用的原始素材，字节保持不变。仅用 Godot 的纹理区域切出地标，没有生成替代图，也没有把概念草图当作整张可点击地图。

- `military_landmarks.png`：1774×887 RGBA。上排依次军旗阵地、精锐、营地、工坊；下排渡口、木关隘、终点城寨、石桥。
  - SHA-256: `1a37b0aa277acc9aaf4320621aef20830892e8d1cc849148338a9b7bf4da8078`
- `ink_landscape.png`：1024×1536 RGB。纸本山河空白底图。
  - SHA-256: `16e55890003219166f0f129d6164bd7915370e19d15dfc7565e655266e00d192`

地图连接来自 `route_map.gd` 的章节图。背景画中的山水不是路径提示；所有可行道路均由实际边绘制，棋子使用相同的三次贝塞尔函数行进。石桥沿用原渡口事件规则，属于外观变化。
